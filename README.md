# skboy-site

Сайт-визитка для `skboy.vip`.

## Локально

Можно открыть `index.html` прямо в браузере. Для проверки серверного сохранения:

```powershell
cargo run
```

Админка: `https://skboy.vip/admin.html` (или секретный адрес из `ADMIN_PATH`).

Пароль задается переменной окружения `ADMIN_PASSWORD` в Render. Используйте новый случайный пароль длиной не менее 16 символов. Не используйте прежний пароль.

## Render

Проект рассчитан на Render Web Service с Rust окружением. `render.yaml` задает постоянный диск для данных сайта. Убедитесь, что домен `skboy.vip` подключен к этому Web Service, а не к старому Static Site.
